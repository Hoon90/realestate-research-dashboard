# realestate-research-dashboard

리서치 리포트 대시보드 — 부동산·기업·경제 분야 국내 주요 기관과 미국·유럽 부동산 리서치(오피스·호텔·물류)의 최신 보고서·보도자료를 발간일 순으로 모아 보는 정적 페이지입니다.
`data/reports.json`, `data/sources.json`은 매일 오전 9시 자동 갱신됩니다.
